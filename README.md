# Проект: Распознавание дорожных знаков (GTSRB)

## Описание
Проект посвящен классификации 12 классов дорожных знаков из датасета German Traffic Sign Recognition Benchmark (GTSRB). Проверена устойчивость моделей к изменению масштаба и освещения.

## Структура проекта
- `code.ipynb` — основной Jupyter Notebook с кодом и визуализациями.
- `baseline_cnn.pth` — файл с сохраненными весами baseline cnn модели.
- `requirements.txt` — список библиотек.

## Установка и запуск
1. Скачайте датасет `GTSRB_Final_Training_Images.zip` с официального сайта и распакуйте в папку `data/`.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Запустите ноутбук `project.ipynb` (выполняйте ячейки последовательно сверху вниз).

## Методология
- **Разделение данных:** Использовано разделение по трекам (`TrackID`), чтобы исключить утечку данных (Data Leakage). Train/Val = 80/20.
- **Аугментации:** Применены `RandomAffine` (масштаб, поворот) и `ColorJitter` (яркость, контраст) только для тренировочной выборки.
- **Модели:** Обучена Baseline CNN (с нуля) и проведен Fine-tuning ResNet18.
- **Метрики:** Accuracy, Macro F1, Матрица ошибок.

## Результаты
- **Baseline CNN:** Accuracy 97.98%, Macro F1 0.9699.
- **ResNet18:** Accuracy 97.36%, Macro F1 0.9588 (обучение остановлено на 3-й эпохе из-за ограничений CPU).
- **Анализ ошибок:** Модель путает визуально похожие знаки (например, 60 и 80 км/ч). Стресс-тест на затемнение показал высокую устойчивость модели.

## Ограничения
Модель не является системой автономного вождения. Она обучена только на 12 классах и не учитывает контекст дорожной сцены.
